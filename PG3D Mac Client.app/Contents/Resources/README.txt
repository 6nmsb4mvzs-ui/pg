PG3D Mac Client 1.68.0

Installing
Double-click PG3D Mac Client. The very first time, macOS asks you to confirm
(System Settings > Privacy & Security > Open Anyway). The app then installs
itself into Applications, sets up everything it needs, and moves the download
to the Trash. Open it from Launchpad or Spotlight after that.

Updating
Download the new version and open the client you already have. It finds the
download, installs it, restarts, and cleans up. No confirmation step again.

Troubleshooting
Settings > Troubleshooting > Copy diagnostic report.

New in 1.20
Rank   Earn XP from playtime (60 XP per minute) and wins (250 XP each) and climb
       Iron to Challenger. Challenger takes roughly 750 hours, and Gold and up
       also need a minimum number of wins. Wins are read from the game's
       Player.log, or link your PG3D player ID under Rank > Ember player
       lookup to use your real all-time wins from Ember's public lookup.
Theme  Recolor every PG3D menu, HUD and icon texture: Crimson, Dark Souls,
       Royal or Icy. Close the game first. Apply again after a PG3D update.
Sky    Add your own sky. A 2:1 panorama wraps all the way around; any other
       image is used on every side. Pick which sky textures to replace.
Theme and sky changes use the same backups and undo as cursor changes.

New in 1.21

New in 1.40
Mouse     The in-game overlay no longer covers the whole screen or keeps
          pulling itself to the front, which could leave the Mac cursor stuck
          in the middle of the game or make clicks need two tries.

          Troubleshooting › Fix stuck mouse) to hand focus back to PG3D.
Theme     New "Cute" theme for the client and the game: soft pink with

New in 1.41
Mouse fix PG3D's own Mac bugs: the system cursor staying visible in the

          press. When PG3D is started from the client (Start or Start with

          the system cursor hidden while the game has it locked, and makes
          the first click count. Settings › Troubleshooting › Mouse fix
          turns it off; it switches itself off if PG3D closes right after
          starting twice in a row.

New in 1.41.1

New in 1.46

          Starting PG3D waits up to 5 minutes (the first start after a game
          update can be slow) instead of failing after 2.
          Clips: game sound stops retrying every 2 seconds without Screen

          Saved logins move into the Keychain one at a time (parallel moves

          Settings > Updates points to GitHub instead of asking for
          Downloads access; the diagnostic report now includes the mouse
          fix lines and how long PG3D was focused.

New in 1.47

          out of the game files once, the next time PG3D is closed. The
          Theme tab is now just the Font tab.
Fixes     File pickers work in the client window: Add image (sky and

Fixes     FPS unlocker works with new PG3D builds: instead of fixed

          The save-clip key only works while PG3D is the app in front, so

New in 1.48.1
Fixes     The FPS unlocker, the mouse fix and the game launcher were missing

New in 1.49
Sky       Normal photos look right as a sky: they become a seamless 360-degree
          view (the photo around the horizon, its colours carried up into the
          sky and down to the ground) instead of a 16:9 photo stretched around
          the whole sky with a seam. Only real 2:1 panoramas are wrapped as
          they are. Sky faces are at least 1024 px, so they're less blurry.
Fixes     The game-file scan no longer files sky, loading-screen and font
          textures under the wrong file (they were skipped when applying);
          the next apply rescans once by itself.
          Account switching: a Steam sign-in that worked is no longer
          reported as failed. The client now also reads Steam's active user,
          and only counts Steam's real logon errors, not words like
          "expired" that appear during a normal sign-in.

New in 1.49.1
Fixes     Loading screens and skies no longer change other textures. The
          scan matched names by fragments, so weapon "Reloading" animations
          counted as loading screens and textures like "SkyHammer" as skies.
          It now needs whole words, real skybox shaders and screen-shaped
          loading images. Textures changed by mistake are put back by
          themselves once (after PG3D is closed); your sky and loading
          screen stay.

New in 1.49.2
Fixes     Settings > Troubleshooting > Restore original game files puts every
          game file the client changed back to the original (if PG3D won't
          open or looks broken). If PG3D closes right after starting while
          mods are applied, the Play tab says so and offers the same button.
          Sky textures keep their original size again (1.49.0 enlarged them).
          The diagnostic report now includes PG3D's own log and its newest
          crash report.

New in 1.50
Queue     Every change to the game files (sky, loading screen, cursor, font,
          resets) goes into one queue and runs in order. Apply is never
          greyed out because something else is busy or PG3D is open:
          changes wait and run by themselves once PG3D closes, and a game
          start waits until queued changes are done. The status line shows
          what's running, what's next and about how long it takes.
Times     Time estimates use the real pace of the running task, and starting
          PG3D uses the median of your last starts, so one slow start no
          longer throws it off; when a step runs long it says so instead of
          "Almost there".
Fixes     If PG3D is running in the background without a window, the Play
          tab says so and offers Quit PG3D. A start with the mouse fix that
          never opens a window is closed after a minute and the fix turned
          off, so the next Start works.

New in 1.51
FPS       The Play tab no longer reports the FPS unlocker as failing while
          PG3D is still loading: it keeps checking for 2 minutes and
          updates the message. Only the frame-rate hook decides; the
          v-sync hook is optional (it is reset every 5 s anyway).
Overlay   A soft dark background behind the overlay text (switch in
          Overlay > Style). FPS now also shows for normal starts (measured
          by the mouse fix) and only ever for the running game. Ping
          measures the match server PG3D talks to, in the background, so
          the overlay never stutters while it measures.
Loading   The Sky tab's loading-screen mode lists every loading image it
          found, plus likely map/preview images (unticked), so you can pick
          which ones get your picture.
Fixes     A queued change that fails now always shows its error. The
          diagnostic report lists recent game-file jobs and what's applied.

New in 1.51.1
Mouse     The mouse fix also catches the macOS arrow appearing in the middle
          of a match (not only after switching apps) and hides it again. It
          is the system cursor, which is why clips never show it.

New in 1.52
Finder    A temporary Finder tab looks through PG3D's files for every texture
          that could be a sky, your mouse cursor or a loading screen, with
          pictures. Pick the right ones, then Copy report (to send back) or
          Use selected (the client uses them right away).
FPS       The FPS unlocker works on builds where it can't find the old hook
          (like 156210): it then sets the frame rate through Unity directly
          and keeps it there.
Cursor    Controller ("Gamepad") cursors are never picked as your mouse
          cursor any more; detection runs again once and an applied cursor
          moves onto the right texture.
Sky       Applying a sky covers all sky textures again unless you untick
          some yourself (1.49.1 left it on only 6).

New in 1.53
Finder    Lists every texture in PG3D, not only likely matches: each group
          (Sky, Cursor, Loading screen, GUI) has Suggested, All textures
          and Selected. Pictures load as you scroll; Show more pages on.
GUI       Finder's GUI group resizes (10-100%) or hides the textures you
          select, sprites and standalone textures alike; Reset selected

New in 1.54
Textures  New Textures tab (Sky, Cursor, Loading screen): every texture in
          PG3D with pictures. Select the right ones and press Use selected:
          the cursor uses your pick and your current sky or loading picture
          is re-applied onto exactly the textures you selected.
GUI       GUI Finder (temporary) only finds and reports GUI pieces, with the

Detection Sky names: any texture with "sky" in its name counts unless it's a
          weapon or effect (lobby skies, foggy nights, map skies). Season
          backgrounds and map previews are ticked as loading screens.
          GamepadCursor is allowed as the cursor again (it is the one), and
          a cursor you picked is kept across scans and game updates.

New in 1.66
HUD       New HUD tab: make parts of the in-match HUD smaller or bigger (top

New in 1.65
HUD       The HUD layout scan also understands NGUI (the UI system PG3D's

New in 1.64

Fixes     The app's programs are built with room for a signature, so macOS's

HUD       Settings > Scan HUD layout: looks through every game file for the

Crash     Fixed PG3D crashing a few seconds after launch. On builds where the
          FPS unlocker can't hook in (like the current one), its fallback
