PG3D Mac Client 1.48.0

Installing
Double-click PG3D Mac Client. The very first time, macOS asks you to confirm
(System Settings > Privacy & Security > Open Anyway). The app then installs
itself into Applications, sets up everything it needs, and moves the download
to the Trash. Open it from Launchpad or Spotlight after that.

Updating
Download the new version and open the client you already have. It finds the
download, installs it, restarts, and cleans up. No confirmation step again.

Troubleshooting
Settings > Troubleshooting > Copy diagnostic report.

New in 1.20
Rank   Earn XP from playtime (60 XP per minute) and wins (250 XP each) and climb
       Iron to Challenger. Challenger takes roughly 750 hours, and Gold and up
       also need a minimum number of wins. Wins are read from the game's
       Player.log, or link your PG3D player ID under Rank > Ember player
       lookup to use your real all-time wins from Ember's public lookup.
Theme  Recolor every PG3D menu, HUD and icon texture: Crimson, Dark Souls,
       Royal or Icy. Close the game first. Apply again after a PG3D update.
Sky    Add your own sky. A 2:1 panorama wraps all the way around; any other
       image is used on every side. Pick which sky textures to replace.
Theme and sky changes use the same backups and undo as cursor changes.

New in 1.21
Cleaner layout: grouped sidebar (GUI is now called Overlay), one button and
card style across every tab, and shorter Rank, Theme and Sky pages with the
advanced options folded away.

New in 1.22
Simpler Rank, Cursor and Overlay pages. Rank shows your rank, a progress
bar and what you need next. Cursor and Overlay use color swatches with a
custom color picker; Overlay has one Style card for everything.
Re-detect cursor moved to Settings > Troubleshooting.

New in 1.23
Rank finds your PG3D player ID by itself: it reads the signed-in ID from
the game's settings when PG3D runs, links it to the Steam account you are
playing on, and refreshes your wins every minute while you play.

New in 1.24
Player Lookup tab: look up any PG3D player ID (name, level, clan, all-time
wins and 30-day stats from Ember's public lookup). Your Steam accounts are
listed with the PG3D ID last seen on each, one click to look them up.

New in 1.25
Player Lookup shows everything the lookup returns: account and currencies,
all 30-day stats, wins per game mode, loadout, weapons with level and
rarity, weapon skins, wear, skin and cape textures (saveable), and the raw
data.

New in 1.26
Compact Player Lookup: one search row with Steam and recent players as
chips, a short header with level, XP and currencies, and tabs (Overview,
Modes, Items, Skins, Raw) for the rest of the data.

New in 1.27
Player Lookup laid out like Ember: Profile (collection, currencies, 30-day
stats, loadout), Wins by mode, Weapons with pictures and a category
filter, and Cosmetics (skin, cape, armor, weapon skins with pictures).
Item pictures come from Ember and are cached on this Mac.

New in 1.28
New look across every tab in the style of Ember: near-black background,
orange accent, Space Grotesk and Inter fonts (bundled), tinted buttons.
Play shows the account, FPS target and launch buttons in one card with
playtime, players online and rank below. Accounts has labelled Save login
and Rename buttons, clear badges, and each account's PG3D name with a
one-click lookup.

New in 1.29
Settings > Appearance recolors the client itself with the same presets as
the in-game Theme tab: Ember (default), Crimson, Dark Souls, Royal, Icy.
Theme and Sky tabs tidied: Restore original only shows when something is
applied, and the apply button names the preset.

New in 1.30
Ranks are tiers only (Iron to Challenger) with a rank-up animation that
plays the next time the client is in front. Start shows progress and a time
estimate, waits for texture changes, and checks the Steam account first.
Theme previews on a game screenshot with one tuned look per preset. Sky
drops rotation; Clips and Cursor are simpler.

New in 1.31
Themes retexture each game texture into the preset palette instead of a
flat tint; sky textures are never themed. Sounds for clicks, switches,
sliders and rank-ups with Settings > Sounds (mute all, rank-up sound,
volume). A saved Steam login is now used when an account has no remembered
Steam token or the token stops working.

New in 1.32
Cursor    Crosshair / Hit marker / Kill icon switch. Install your own hit
          marker or kill icon PNG and apply it (when the game has one).
HUD       New tab: shrink or hide PG3D's own HUD pieces. Scans the game once.
Theme     Game font: swap PG3D's text font (Russo One, Bangers, Bebas Neue,
          Press Start, or import your own .ttf/.otf). Text drawn with
          pre-baked fonts keeps its original look.
Sky       Loading screen: use any image from your library as the loading
          screen.
Overlay   Rank widget: your tier and progress bar in game.
Clips     Game sound: records PG3D's own audio only (macOS 13+), no music
          or other apps. "Copy after saving" and a Copy button put clips
          straight on the clipboard for Discord or Messages.
Settings  Rescan game files lives under Troubleshooting.
Play      Last session: time played, XP, wins and clips after you close PG3D.

New in 1.33
Updates   New versions are published as releases of the private GitHub repo.
          In Settings › Updates, paste a read-only GitHub token once and the
          client downloads and installs new versions by itself (checks every
          30 minutes, never mid-game). Dropping a zip into Downloads still
          works too.

New in 1.34
Style     Settings › Appearance › Style: "Noble" gives the client gold
          frames, serif titles and navy backgrounds, inspired by the League
          of Legends client. "Modern" is the look you know.
Motion    Smoother hover effects, button presses and page transitions in
          both styles. Turn them off with the Animations switch.

New in 1.35
Rank up   Smoother rank-up animation, a much fuller and louder sound (rising
          whoosh, impact and chord), and a trophy road when you climb two or
          more ranks at once: the camera glides along every rank you passed,
          each one lighting up with its own note, before the new rank lands.

New in 1.36
Rank up   Cinematic rank-up sound: an accelerating taiko roll while the
          emblem charges, then a deep brass "BRAAAM" with sub boom and crash,
          resolving into a big choir and brass chord in a long hall reverb.
          Trophy road steps hit with a drum and a rising brass stab.

New in 1.37
Rank up   New rank-up sound in the style of League's promotion: magic
          gathering as shimmering bells climb, then a soft deep swell, a big
          glassy bell chord, a crystal sparkle run and an airy choir pad.
          Settings › Sounds › Rank-up sound file lets you use your own sound
          file instead (MP3, WAV, M4A, OGG, FLAC).

New in 1.38
Rank up   Deeper, warmer rank-up sound: a reverse swell rushing into the hit,
          a soft deep boom with a short metallic shing, and a warm string and
          low choir chord in a dark hall. No more high music-box notes.

New in 1.39
PG3D updates  When Steam has a Pixel Gun 3D update waiting, the Play tab
          says so and "Install update" installs it through Steam. Pressing
          Start with an update pending installs it first.
Mods      After a PG3D update (or Steam putting back original files), your
          cursor, hit marker, HUD, theme, font, sky and loading screen are
          re-applied by themselves, and the client re-finds each change in
          the new game files. Turn off in Settings › Updates.

New in 1.40
Mouse     The in-game overlay no longer covers the whole screen or keeps
          pulling itself to the front, which could leave the Mac cursor stuck
          in the middle of the game or make clicks need two tries.
          If it still happens: press Ctrl+Shift+M in game (or Settings ›
          Troubleshooting › Fix stuck mouse) to hand focus back to PG3D.
Theme     New "Cute" theme for the client and the game: soft pink with
          deeper rose accents.

New in 1.41
Mouse fix PG3D's own Mac bugs: the system cursor staying visible in the
          middle of the screen, and clicks that only work on the second
          press. When PG3D is started from the client (Start or Start with
          FPS Unlocker), a small helper is loaded into the game that keeps
          the system cursor hidden while the game has it locked, and makes
          the first click count. Settings › Troubleshooting › Mouse fix
          turns it off; it switches itself off if PG3D closes right after
          starting twice in a row.

New in 1.41.1
Sounds    Click, switch, slider and tab sounds are now soft taps instead of
          beeps, and loud enough to actually hear (they were about 35 dB
          quieter than the rank-up). Fixed a small pop at the end of the
          rank-up charge sound.
Launch    Start and Start with FPS Unlocker open Steam first if it isn't
          running (the direct launch used for the mouse fix needs it).

New in 1.42
Sounds    New button sounds that follow your style (Settings › Appearance):
          Modern sounds like an ASMR mechanical keyboard (crisp keycap click,
          deep thock, lighter clack on the way back up); Noble sounds like the
          League client (glassy metallic tinks, a magic whoosh on tabs, a
          brighter chime on main buttons).

New in 1.43
Sounds    Button sounds are now real recordings instead of generated tones:
          Modern uses mechanical key switches warmed into a creamy thock,
          Noble uses crisp ticks and airy whooshes in a small bright hall.
          Recordings by Kenney (kenney.nl), CC0; see web/sounds.

New in 1.44
Sounds    Modern: one deep, smooth "clock" for every button (higher or lower
          per control). Noble: League-style steel - a blade draw on main
          buttons, a softer draw on tabs, a metal latch on clicks and a metal
          click on switches, in a small bright hall. Recordings by Kenney
          (kenney.nl), CC0.

New in 1.45
Sounds    Settings > Sounds > Button sounds: pick the sound for each control
          (click, main button, switch on/off, tab, slider) separately for the
          Modern and Noble styles. Click a sound to hear and choose it, use
          + Add file for your own sounds (MP3, WAV, M4A, OGG or FLAC, up to
          3 MB) and Reset to defaults to go back. 131 recordings by Kenney
          (kenney.nl), CC0; see web/sounds.

New in 1.46
Fixes     Session reports no longer show huge fake gains after switching
          Steam accounts: PG3D keeps the previous account's player ID saved
          until it signs in, so the client now waits for a stable ID that
          isn't another account's before linking it.
          Starting PG3D waits up to 5 minutes (the first start after a game
          update can be slow) instead of failing after 2.
          Clips: game sound stops retrying every 2 seconds without Screen
          Recording permission and says so on the Game sound switch; the
          screen is captured in its native pixel format.
          Saved logins move into the Keychain one at a time (parallel moves
          failed at startup).
          Settings > Updates points to GitHub instead of asking for
          Downloads access; the diagnostic report now includes the mouse
          fix lines and how long PG3D was focused.

New in 1.47
Removed   In-game themes and HUD resizing. Anything still applied is taken
          out of the game files once, the next time PG3D is closed. The
          Theme tab is now just the Font tab.
Fixes     File pickers work in the client window: Add image (sky and
          loading screen), Import PNG, font Import and button sounds now
          open a file dialog. The account nickname box works again too.
          Player Lookup: the clan shows its emblem instead of a giant line
          of image data.
          Clips record only while PG3D is really running: the client now
          checks the game's own process (helpers that mention the game's
          path no longer count), waits until it has been up for 10 seconds,
          and the "Only while PG3D runs" switch is gone.
          Every normal start now loads the mouse fix, including the start
          after a Steam Guard code.

New in 1.47.1
Fixes     The client window opens again (1.47's file-dialog code stopped it
          from starting). If the window ever fails to open, the client now
          opens in your browser instead of not appearing at all. The
          in-game overlay had the same kind of startup error and starts
          again too.

New in 1.48
Fixes     FPS unlocker works with new PG3D builds: instead of fixed
          addresses for one build, it finds Unity's frame-rate functions in
          the game by their code. The Play tab only warns if the unlocker
          actually failed on your build.
          The save-clip key only works while PG3D is the app in front, so
          pressing it in other apps no longer saves clips or shows errors.
